#  Sistema de Gestión Inmobiliaria

## Descripción

### Aplicación web desarrollada para **centralizar y facilitar la gestión de una inmobiliaria**. El sistema permite organizar en un solo lugar la información de propietarios, inquilinos, inmuebles, reservas y pagos, evitando la gestión manual y facilitando el seguimiento de las operaciones.


El proyecto fue desarrollado como trabajo grupal utilizando **ASP.NET Core MVC, C#, Entity Framework Core, SQL Server y Vue.js**.

## Funcionalidades principales

* Gestión de propietarios e inquilinos.
* Gestión de tipos e inmuebles.
* Registro y administración de reservas.
* Consulta de disponibilidad.
* Gestión de pagos.
* Administración de usuarios y roles.
* Gestión de imágenes de los inmuebles.
* Auditoría de reservas y pagos.
* Reportes y consultas.

## Acceso al sistema

El sistema cuenta con un usuario administrador creado mediante la configuración inicial de Entity Framework Core.

**Correo:** `admin@inmobiliaria.com`
**Contraseña:** `1234`

El administrador cuenta con permisos para gestionar usuarios y acceder a las funcionalidades administrativas.

## Base de datos

La aplicación utiliza **SQL Server** y **Entity Framework Core** para la gestión de datos.

La estructura de la base de datos se administra mediante migraciones de Entity Framework Core.

También se incluye el archivo `BDInmobiliaria.sql` para crear la base de datos.

Se recomienda tener instalado:

* SQL Server 2022
* SQL Server Management Studio (SSMS)
